# JL Mixing Automation v1.1 Implementation Checklist

**Status:** Approved implementation plan and Definition of Done

## 1. Scope-control checklist

- [ ] Treat the four v1.1 scope-freeze documents as authoritative.
- [ ] Preserve v1.0.4 behavior unless explicitly changed.
- [ ] Do not implement rejected or superseded proposals.
- [ ] Route newly discovered user-visible changes back to design review.
- [ ] Keep expanded audio QC, migration, archive, and other deferred features out of v1.1.
- [ ] Add clear explanatory comments to new or materially changed code.

## 2. Phase 1 — Shared foundations

- [ ] Validate governing JSON before mutation.

- [ ] Report useful JSON paths on schema failure.

- [ ] Resolve studio, client, project, revision, and delivery boundaries safely.

- [ ] Readable folder-name sanitization.
- [ ] Reserved-name and empty-result checks.
- [ ] Case-insensitive ID collision detection.

### Transaction services

- [ ] Atomic JSON write/replace helper.
- [ ] Same-filesystem staged-directory commit helper.

- [ ] Backup/restore helpers with failure reporting.

- [ ] Add failure-injection hooks for tests.

### Path and ownership safety

- [ ] Safe absolute and relative path validation.

### Markdown services

- [ ] Byte-for-byte preservation outside the managed section.

- [ ] UTF-8 and final-newline enforcement for generated Markdown.

### Project-state services

- [ ] Derive Setup/In progress/Approved/Delivered.
- [ ] Validate contiguous revisions and directory correspondence.
- [ ] Validate state pointers.
- [ ] Validate approval-field pair rules.
